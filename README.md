An autonomous data pipeline that scrapes the complete daily transaction floorsheet directly from the **Nepal Stock Exchange (NEPSE)**, archives every trading day as version-controlled CSVs, and derives two per-broker summary files for each day — fully automated on GitHub Actions.

---

## 📦 What's inside

| Folder | Grain | Rows/day (approx) | Generated by |
| :--- | :--- | :--- | :--- |
| `Floorsheet/YYYY-MM-DD.csv` | one row per contract | 40k – 110k | daily scraper |
| `Summary/YYYY-MM-DD_brokers.csv` | one row per broker × scrip | ~12k – 14k | `DailySummary.py` |
| `Summary/YYYY-MM-DD_broker_totals.csv` | one row per broker | ~91 | `DailySummary.py` |

Column meanings, sign conventions, and regeneration recipes for the Summary files: **[`Summary/README.md`](Summary/README.md)**.

## 🕒 Schedule & trading calendar

- The Action runs **Monday–Friday at 15:36 NPT** (`51 9 * * 1-5`, = 09:51 UTC), ~36 minutes after the 15:00 close.
- On public holidays NEPSE returns the previous day's records; the `businessDate` guard in [`scrape_daily.py`](scrape_daily.py) detects this and skips the save — so no stale or empty files get committed. Holidays simply have no file.
- NEPSE shifted its trading week from **Sun–Thu to Mon–Fri in April 2026** (last Sunday-session file `2026-04-05`, first Friday-session file `2026-04-10`). The archive covers both eras exactly as published — you will find Sunday files up to April 2026 and none after.

## 📆 Data coverage & provenance

- **Range:** every NEPSE trading day from **2025-01-01** to the latest close. The scheduled Action appends one file per trading day — the archive stays current by itself.
- **Provenance:**
  - Trading days covered by this repository's own scraper (**2026-09-17 onward**) were retrieved directly from NEPSE and carry the full 14-column schema.
  - Earlier days — all of 2025, backfilled up to **2026-10-12** including any gap days the scraper missed — come from **SocrateAI's MIT-licensed [`nepse-open-data`](https://github.com/socrateai-official/nepse-open-data)** archive of NEPSE floorsheets, remapped to this archive's schema. Backfilled files leave `tradeTime`, `tradeBookId` and `stockId` **blank**.
  - Quick check: `tradeTime` blank ⇒ backfilled row.
  - One known repair: on **2026-04-29**, contract `2026042901000179` (NIBLGF, 1,000 shares) reached all third-party copies with rate/amount `0.0`. It was restored to **9.14 / 9,140.00** by reconciliation against MeroLagani's official day totals (qty 12,134,360 / NPR 4,986,303,313.38), which the repaired file now matches exactly.
- Full provenance ledger in [`credit.md`](credit.md); licence & attribution in [`NOTICE.md`](NOTICE.md).

## 🌐 How to access the data (no clone needed)

Every daily CSV is public and can be loaded directly into pandas, Colab, R or Excel. You do **not** need to clone the repository.

### 1. Raw URL pattern

```text
Floorsheet: https://raw.githubusercontent.com/jagdishsah126/nepse-floorsheet-archive/main/Floorsheet/<YYYY-MM-DD>.csv
Summary:    https://raw.githubusercontent.com/jagdishsah126/nepse-floorsheet-archive/main/Summary/<YYYY-MM-DD>_brokers.csv
            https://raw.githubusercontent.com/jagdishsah126/nepse-floorsheet-archive/main/Summary/<YYYY-MM-DD>_broker_totals.csv
```

### 2. One line in pandas / Jupyter / Colab

```python
import pandas as pd

date = "2026-10-30"   # any trading day from 2025-01-01 onward
base = "https://raw.githubusercontent.com/jagdishsah126/nepse-floorsheet-archive/main"

trades  = pd.read_csv(f"{base}/Floorsheet/{date}.csv", dtype={"contractId": str})
brokers = pd.read_csv(f"{base}/Summary/{date}_brokers.csv")

print(f"{date}: {len(trades):,} contracts | {len(brokers):,} broker×scrip rows")
```

> Tip — keep `contractId` as a string; in Excel it may otherwise display as scientific notation.

### 3. Direct download via terminal

```bash
curl -O https://raw.githubusercontent.com/jagdishsah126/nepse-floorsheet-archive/main/Floorsheet/2026-10-30.csv
```

### 4. Whole-archive caution

This repository is now years of daily data: a full clone is several GB, and loading every Floorsheet day into one DataFrame is multi-GB in memory:

```python
# Only for a full local clone + enough RAM. Prefer Summary/ for broker-level questions —
# each day's summary is ~10× smaller than the floorsheet.
import glob
import pandas as pd

all_files = glob.glob("Floorsheet/*.csv")
master_df = pd.concat([pd.read_csv(f) for f in all_files], ignore_index=True)
print(f"{len(master_df):,} raw contract rows across {len(all_files)} days")
```

## 📄 Floorsheet CSV schema

14 columns, fixed order on every file:

| Column | Example | Description |
| :--- | :--- | :--- |
| `contractId` | `2026103001015997` | Unique contract ID |
| `stockSymbol` | `SANIMA` | Ticker symbol |
| `buyerMemberId` | `45` | Buyer broker number |
| `sellerMemberId` | `62` | Seller broker number |
| `contractQuantity` | `100` | Shares transacted |
| `contractRate` | `412.5` | Price per share (NPR) |
| `contractAmount` | `41250.0` | `quantity × rate` (NPR) |
| `businessDate` | `2026-10-30` | Trading date |
| `tradeBookId` | `201556390` | NEPSE trade-book ID *(blank on backfilled rows)* |
| `stockId` | `171` | NEPSE internal security ID *(blank on backfilled rows)* |
| `buyerBrokerName` | `Imperial Securities Company Pvt. Ltd.` | Buyer broker name |
| `sellerBrokerName` | `Capital Max Securities Ltd` | Seller broker name |
| `tradeTime` | `2026-10-30T14:59:59…` | Transaction timestamp *(blank on backfilled rows)* |
| `securityName` | `Sanima Bank Limited` | Full company name |

## 🛠️ Running locally

```bash
pip install -r requirements.txt   # only the scraper needs these
python scrape_daily.py            # scrape today's floorsheet (Mon–Fri, NPT)
python DailySummary.py            # build today's Summary/ files (stdlib-only, no network)
python DailySummary.py --date 2026-10-30 --force
python DailySummary.py --broker 58          # broker 58's day, printed, no files written
python summaryBackfill.py --dry-run         # list Floorsheet days missing a Summary pair
```

The Summary scripts are stdlib-only — no pandas, no installs, no network access.

---

## 🚀 Deploy your own instance

1. Fork the repository (or create a fresh one with these scripts).
2. **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**
   *(otherwise the push step fails with `403 Permission Denied`)*.
3. Both workflows also support manual runs via **Run workflow** in the Actions tab:
   - `Daily NEPSE Floorsheet Scraper` — scrape a day on demand;
   - `Summary Backfill` — regenerate `Summary/` for past days missing one (optional `start`/`end`/`limit` inputs).
