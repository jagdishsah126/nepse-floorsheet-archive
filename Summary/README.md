# Summary

Daily broker summaries generated by `DailySummary.py` from `Floorsheet/YYYY-MM-DD.csv`.

## Files

| File | Grain | Rows/day (approx) |
|---|---|---|
| `YYYY-MM-DD_brokers.csv` | one broker × one scrip | ~12,000 |
| `YYYY-MM-DD_broker_totals.csv` | one broker | ~91 |

## `*_brokers.csv`

| Column | Meaning |
|---|---|
| `business_date` | Trading date |
| `broker_id` | NEPSE broker/member ID |
| `broker_name` | Broker name as written in the floorsheet |
| `stock_symbol` | Scrip symbol |
| `buy_qty` | Shares bought by this broker's clients |
| `buy_amount` | Rupees spent buying |
| `buy_vwap` | `buy_amount / buy_qty` (blank if no buys) |
| `sell_qty` | Shares sold by this broker's clients |
| `sell_amount` | Rupees received selling |
| `sell_vwap` | `sell_amount / sell_qty` (blank if no sells) |
| `net_qty` | `buy_qty − sell_qty` (negative = net sold) |
| `net_cash` | `sell_amount − buy_amount` (positive = net cash in, negative = net cash out) |
| `gross_turnover` | `buy_amount + sell_amount` |
| `contracts` | Number of contracts on both sides |

`buy_vwap` and `sell_vwap` are volume-weighted averages, not a single trade price.

## `*_broker_totals.csv`

Same columns aggregated across scrips, minus `net_qty`: summing share counts
across different scrips is not meaningful. `net_cash` is meaningful in rupees.
`scrips_traded` counts distinct symbols where the broker appeared on either side.
Sorted by `gross_turnover` descending.

## Sign convention

A broker buying 1,203 shares worth Rs 360,900 and selling 7,585 shares worth
Rs 3,451,175 gets:

- `net_qty = -6,382` (net sold)
- `net_cash = +3,090,275` (net cash received)

## Regenerate

```bash
python3 DailySummary.py --date 2026-10-27
python3 DailySummary.py --date 2026-10-27 --force
```

One broker's view, without writing files:

```bash
python3 DailySummary.py --broker 58
```

The script is stdlib-only and never downloads anything. Each day adds two new
files; existing days are never rewritten unless `--force` is passed.
